# OverlayKit

Universal toolkit for adding logos, watermarks, badges and visual overlays to web content.

## Status

OverlayKit is currently under active development.

Current planned packages:

- `@overlay-kit/shared`
- `@overlay-kit/core`
- `@overlay-kit/dom`
- `@overlay-kit/react`

## Goals

- Framework-independent core
- JavaScript and TypeScript support
- DOM integration
- React integration
- Responsive positioning
- Accessible overlays
- Small and dependency-free packages
